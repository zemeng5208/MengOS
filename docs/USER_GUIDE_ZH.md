# FeatherTerminal 用户手册（中文）

> 面向刚接触 MengOS 的同学。这里写清楚每个侧栏页面怎么用、显示的数据从哪来、
> 哪些还没做。全部功能都在本机运行，不上传任何数据。

## 0. 先认识窗口

打开 FeatherTerminal 后，窗口分成三块：

- **左边**：终端本体，可以开多个标签页（`Ctrl+Shift+T` 新建，`Ctrl+Shift+W` 关闭）。
- **右边**：侧栏，共 6 个页面。
- **左下角一排图标**：点一下切换侧栏页面；按 `Ctrl+Shift+B` 可以把整个侧栏收起来。

侧栏顶部永远显示两行：页面名字，和「当前目录」——它跟着**当前标签页**里的 shell 走，
你在终端里 `cd` 到哪，它就显示到哪。

## 1. 文件更改（第 1 个图标，铅笔）

**用途**：看当前目录所在 Git 仓库里「改了哪些文件」，以及每个文件具体改了哪几行。

**怎么用**

1. 在终端里 `cd` 到某个 Git 仓库（例如 `cd ~/我的项目`）。
2. 点侧栏第 1 个图标。
3. 上面列出所有有更改的文件，每行前面的两个字母就是 `git status --short` 的状态码
   （`M` 改过、`A` 新加进暂存区、`D` 删了、`??` 还没被 Git 跟踪……）。
4. 点某个文件，下面显示它的 diff：
   - 绿底 `+` 开头 = 新增的行
   - 红底 `-` 开头 = 删除的行
   - 蓝灰加粗 `@@` = 这一段改动的位置
   - 灰色 = Git 自己的信息行（`diff --git`、`index`、`---`、`+++` 等）
5. 顶部「刷新」按钮可以立刻重读；页面显示着的时候每 3 秒也会自动刷新文件列表。

**数据来源**：真的调用 `git status --porcelain=v1` 和 `git diff`（不是自己比文件内容）。
所以显示的内容和你自己在终端里敲 `git diff` 看到的一致。

**注意**

- 当前目录不是 Git 仓库时，页面会写「当前目录不是 Git 仓库，无法显示文件更改」。
- 没装 git 时会写「未安装 git」。
- diff 超过 5000 行只显示前 5000 行，并提示「已截断」。
- 未跟踪的新文件会显示「新文件（未跟踪）」和它的内容（最多 200KB），按全部新增行显示。

## 2. 网络连接（第 2 个图标，网络）

**用途**：看**当前这个标签页里运行的程序**开了哪些网络连接。

**怎么用**

1. 在终端里跑一个联网程序，例如 `python3 -m http.server 8000`。
2. 点第 2 个图标，2 秒内就能看到：
   - 「监听中的端口」分组里出现 `python3(1234) TCP 监听 0.0.0.0:8000 LISTEN`
   - 有程序连上来时，「连接」分组里出现 `... ESTABLISHED`
3. 换到另一个标签页，页面会立刻按那个标签的程序重新统计。

**数据来源**：全部从 `/proc` 读——先用 `/proc/<pid>/stat` 的父进程号找出当前 shell 的整棵
进程树，再读每个进程 `/proc/<pid>/fd/` 里的 `socket:[编号]`，最后到
`/proc/net/tcp`、`tcp6`、`udp`、`udp6` 里按编号匹配。

**注意**

- 只能看到**你自己的**进程；别人的进程读不到，会直接跳过。不需要 root，也不用 sudo。
- 底部那行说明很重要：「数据来源：本机连接表（/proc/net）。仅表示本机存在该连接，
  不代表对方已收到数据。」
- 页面不可见时不会刷新（省电）；切回来会立刻刷新。

## 3. 文件树（第 3 个图标，文件夹）

**用途**：用鼠标浏览当前目录，不用敲 `ls`。

**怎么用**

1. 点第 3 个图标，列出当前目录里的东西。
2. 点文件夹左边的三角展开，点文件在下面看内容预览（最多显示 32MB）。
3. 顶部「显示隐藏文件」开关控制要不要显示 `.` 开头的文件；「刷新」立刻重读。

**数据来源**：直接读文件系统（Rust 的 `read_dir`），不经过任何缓存或索引。

## 5. 个人资料（第 5 个图标，人像）

**用途**：看这台机器和这个账号的基本情况，以及你最常用哪些命令。

**怎么用**：点第 5 个图标，「刷新」按钮可以重读一遍。

**显示内容与数据来源**

| 显示项 | 来源 |
|---|---|
| 用户名、UID、所属组 | `/proc/self/status` + `/etc/passwd` + `/etc/group` |
| 主机名 | `/proc/sys/kernel/hostname` |
| 系统版本 | `/etc/os-release` 的 `PRETTY_NAME` |
| 内核版本 | `/proc/sys/kernel/osrelease`（等于 `uname -r`） |
| 当前 shell | 环境变量 `SHELL` |
| 终端版本 | 编译时注入的版本号 |
| 本次开机 | `/proc/uptime` |
| 常用命令 Top 10 | `~/.zsh_history`（或 `$HISTFILE`） |

**隐私说明**

- 常用命令**只统计命令名**：`git commit -m 密码123` 只算作 `git`，参数一律不显示。
- 页面已经写明：「只统计命令名称，不显示参数。数据只在本机读取，不上传。」
- 历史文件不存在时显示「暂无历史记录」。

「AI 使用统计」一栏目前显示「未关联（FeatherBot 尚未实现）」。

## 7. 常用快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Shift+T` | 新建标签页 |
| `Ctrl+Shift+W` | 关闭当前标签页 |
| `Ctrl+Shift+F` | 打开/关闭搜索栏 |
| `Ctrl+Shift+B` | 显示/隐藏侧栏 |
| `Ctrl+Shift+C` | 复制选中文字 |
| `Ctrl+Shift+V` | 粘贴 |
| `Ctrl+PageUp` / `Ctrl+PageDown` | 上一个 / 下一个标签页 |

## 8. 出问题怎么办

- 页面显示「未知」「暂无」：多半是那台机器上确实没有这个文件（例如还没有 zsh 历史）。
- 页面一直空着：先在终端里确认对应命令（`git status`、`ss -tnp`）本身有输出。
- 想更新终端版本：在终端里跑 `mengos-update-terminal`，它会从 `dev-latest` 下载最新的
  `.deb` 装上，然后关掉所有窗口重新打开。
